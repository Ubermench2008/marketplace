# Фронтенд «Рядом»

Исходники: [HTML, CSS и JavaScript](../src/main/resources/static). Отдельной сборки не требуется.

## Запуск

Веб-интерфейс доступен на [localhost:8080](http://localhost:8080/) после [запуска приложения](../README.md#локальный-запуск).

Для отдельного запуска нужен Node.js. Команда из корня репозитория:

```powershell
node frontend/serve.mjs
```

Интерфейс доступен на [localhost:5173](http://localhost:5173/). Запросы к API и изображениям проксируются на порт 8080, поэтому бэкенд также должен быть запущен.

Проверка синтаксиса и импортов:

```powershell
node frontend/check.mjs
```
